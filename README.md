## 📜 独立宣言 (The Manifesto)

我们正在经历一场**“智力逃逸”**。当无数聪明的头脑涌入虚拟的互联网和 AIGC 寻找捷径时，物理世界正在失去它的“底层逻辑守护者”。

市面上的少儿编程与创客教育，正在用一盒盒昂贵的“电子积木”毒害下一代。它们把底层原理封装得天衣无缝，孩子们只需拼接模块，就能得到一个看似完美的“避障小车”。**这是黑盒教育，是对工程常识的阉割。**

真正的工程师知道：**完美是不存在的，工程是妥协（Trade-off）的艺术。**

> - 当齿轮咬合时，如果没有算过**公差（Tolerance）**，电机就会卡死发烫。
> - 当传感器读取数据时，如果不懂**滤波（Filtering）**算法，数字就会像心电图一样疯狂跳动。
> - 机器之所以能画出优美的曲线，是因为背后流淌着**微积分方程**。

本书是一套**开源的“认知外骨骼”**。它不教你如何组装现成的玩具，它教你如何用数学当图纸，用物理当引擎，用失败的废品当养料，最终夺回对这个物质世界的解释权与立法权。

## 📐 核心选品公理 (The L-H-W Metric)

本书中的每一个项目，均需通过严格的建构主义三维审计：

- **[ L ] Low Floor (低地板)**：不设虚高的门槛。用最常见的 3D 打印件或旧玩具起步，允许粗糙，允许破坏。
- **[ H ] High Ceiling (高天花板)**：直通大学级别的第一性原理。一个简单的凸轮玩具，终点是运动学微分方程。
- **[ W ] Wide Walls (宽墙壁)**：高度的可迁移性。学懂了行星齿轮，就能向机器狗、差速器甚至艺术装置发散。

## 🗂️ 核心架构与目录规划 (The Blueprint)

本书分为四个进阶阶段，从培养纯粹的机械直觉，到跨越软硬件鸿沟，最终抵达本科级别的系统工程。

### Phase 1: 纯粹机械直觉 (The Naked Mechanic)
> *不碰代码，远离屏幕。建立对重力、摩擦力、杠杆与死点的绝对肌肉记忆。*
* **Ch 1.0 开膛破肚计划**：如何优雅地拆解一台报废打印机？（齿轮、光轴、步进电机的寻宝之旅）
* **Ch 1.1 纸上谈兵与降维打击**：从二维草图到三维实体（Tinkercad 与基础空间几何）
* **Ch 1.2 机构的生命力 (Automata)**：曲柄滑块、苏格兰轭与凸轮。为什么机器会“卡死”？
* **Ch 1.3 传动与背隙的哲学**：造一个齿轮减速器，顺便讲讲什么是“过盈配合”与“公差”。

### Phase 2: 数字桥梁 (The Digital Bridge)
> *打破电子积木的谎言。直面跳动的电压、烧毁的芯片与“肮脏”的模拟信号。*
* **Ch 2.0 拒绝扩展板**：面包板上的欧姆定律。为什么你的 LED 会烧掉？
* **Ch 2.1 传感器的谎言**：用 Arduino 读取超声波。认识系统“噪声”，手写第一个滑动平均滤波算法。
* **Ch 2.2 信号流程图 (IPO)**：用电气思维解构机械，造一个简单的二维激光云台。
* **Ch 2.3 制造你的主板**：从面包板到立创 EDA/KiCad。画出人生第一块 PCB，体验铁板烧式贴片焊接。

### Phase 3: 微积分引擎 (The Calculus Engine)
> *数学不再是试卷上的符号，它是控制机器运动的终极咒语。*
* **Ch 3.0 机器的闭环**：为什么直线走不直？从开环步进到编码器反馈，手写 PID 算法（循迹小车终极解法）。
* **Ch 3.1 极坐标的具象化**：造一台物理绘图仪（Polar Plotter）。用三角函数和四阶龙格-库塔法（RK4）指挥画笔。
* **Ch 3.2 向量与矩阵的实体**：CoreXY 结构全解析。如何用两条静止的皮带驱动整个平面？
* **Ch 3.3 挑战无人区**：微分万向轮底盘（Swerve Drive）的逆向运动学推导与 3D 打印实现。

### Phase 4: 顿悟日志与军火库 (The Epiphany Logs)
> *记录真实的失败（Negative Samples），提供实战武器库。*
* **Appx A. 工程师的排障指南**：当机器冒烟时，你的大脑该如何运转？
* **Appx B. “防智商税”采购清单**：万用表、电烙铁、打印机与开源硬件选型指南 (Hardcore BOM)。
* **Appx C. 降维打击教材库**：被藏起来的国外神级微积分/物理教材与可视化工具（Desmos）推荐。
* **Appx D. [极客彩蛋] 破解系统的黑盒**：手搓一个 API 监控可视化节流阀（JS 注入实战）。

## 🧬 参与协作 (The Beta Test Workflow)

本书并非“瀑布流”式的闭门造车，而是一个在 GitHub 上持续迭代的 **敏捷系统 (Agile System)**。

**🔄 研发流 (Genesis Loop)：**
1. 我会在自己的亲戚/学生身上进行 Beta 测试。
2. 收集他们踩过的坑、算错的公差、烧坏的电路板。
3. 将这些“失败（Loss Function）”记录在每个章节的 `[顿悟时刻 / Epiphany]` 模块中。

如果你是一位硬核家长、极客或教育者，**欢迎 Fork 本仓库，提交你在实战中遇到的 Issue 或 PR**。让我们一起，为这个物理 AI 时代，建立新的标准。
